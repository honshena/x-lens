## 简短描述

在 VS Code 中专注浏览 X 推荐动态，通过本地伴随应用查看帖子、媒体和评论。

English: A focused X feed reader for VS Code, powered by a locally running companion app.

## 市场介绍

X-Lens 将推荐动态带进 VS Code，以单栏阅读界面浏览帖子、图片、视频和评论。它支持下滑加载、帖子详情、选中文字自动翻译、浅色与深色主题，以及快捷键隐藏阅读内容。

X-Lens 是独立项目，与 X 没有关联或背书。VSIX 包含应用本体，并在打开阅读器时启动本地服务。
